Clockwork Twins is a spot-the-difference game: three hand-drawn scenes (a clockmaker's attic, a starlight bakery, a botanist's greenhouse), seven hidden changes hiding in each, played with mouse and keyboard in a desktop browser. Found differences get a gold ring on both pictures, wrong clicks cost five seconds, hints pulse the spot you missed, and the clock is always ticking.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. Or hand the game in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.

## How to play

- Click a difference in either picture — a gold ring marks it on both sides.
- Arrow keys move the crosshair, Enter checks the spot it stands on.
- H spends a hint, P pauses, M mutes, R restarts the level, N goes to the next level.
- Find all 7 differences before the timer runs out. Streaks earn bonus points; three stars need no hints and time to spare.
